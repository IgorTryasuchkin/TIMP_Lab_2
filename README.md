# Лабораторная работа №2. Обработка ошибок

Обработка исключений в модулях шифрования (русский язык).

- `gronsfeld/` — шифр Гронсфельда
- `transposition/` — шифр табличной маршрутной перестановки
  (запись по строкам слева направо, считывание по столбцам справа налево; ключ — число столбцов)

Сборка (нужна UTF-8 локаль):

    cd gronsfeld && make && ./gronsfeld
    cd transposition && make && ./transposition
